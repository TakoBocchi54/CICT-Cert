# CICT-Cert

CICT-Cert is a blockchain-based seminar certificate issuance and
verification system using Soulbound Tokens (SBTs).

## Technology Stack

### Frontend
- React
- Tailwind CSS

### Backend
- Node.js
- Express.js

### Database
- PostgreSQL

### Blockchain
- Solidity
- ERC-5192
- Polygon

## Project Status

Initial Agile Planning and System Development
